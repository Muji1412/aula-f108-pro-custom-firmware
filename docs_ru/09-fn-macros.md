# 9. FN-макросы: свои FN-комбинации

FN-макрос заставляет одну FN-комбинацию выполнить короткий список заводских FN-действий. Список можно выбирать по текущему
подключению или системному режиму. Типичный случай: одна клавиша, чтобы переносить клавиатуру между компьютерами.

```
FN+W   по кабелю -> режим Mac + донгл 2.4G      2.4G или Bluetooth -> режим Windows + кабель
```

Макросы необязательны. Без файла макросов сборка и `patch_data.json` в точности совпадают с обычным патчем.
Полное описание на английском: [../docs/09-fn-macros.md](../docs/09-fn-macros.md).

## Готовый вариант: переключение PC / Mac

Для Windows-компьютера на кабеле и Mac на донгле 2.4G. Компилятор не нужен:

```
python firmware\apply_patch.py путь\к\AULA_F108_Pro_Firmware.exe --patch firmware\macros\pc-mac-toggle.patch.json
```

Получившийся `_CUSTOM.exe` прошивается как обычно ([01-flashing.md](01-flashing.md)). В нём обычный патч плюс макрос.

## Заводские FN-комбинации (в инструкции их нет)

| Клавиши | Действие |
|---|---|
| FN+4 | кабель (USB) |
| FN+\` | донгл 2.4G (удержание: сопряжение) |
| FN+1 / FN+2 / FN+3 | Bluetooth 1 / 2 / 3 (удержание: сопряжение) |
| FN+W / FN+E / FN+R / FN+Q | системный режим Windows / Mac / iOS / Android |
| FN+B | заряд батареи на подсветке |
| FN+нажатие колёсика | колёсико: громкость / меню |
| FN+RShift, FN+/, FN+RAlt | боковые полосы: эффект, цвет, яркость |

## Файл макросов

```json
{
 "macros": [
  {"key": "FN+W", "if": {"connection": "wired"}, "then": ["MAC", "2.4G"], "else": ["WIN", "USB"]},
  {"key": "FN+J", "do": ["WIN", "USB"]}
 ]
}
```

- `key`: `FN+<клавиша>`. Если у комбинации есть заводское действие, макрос его заменяет (сборка об этом пишет). Клавиша без
  заводского действия (FN+J, FN+M ...) ловится только при зажатом FN, сама буква в компьютер не уходит. F1..F12, LCtrl, LWin
  нельзя: их FN-действие зависит от системного режима.
- `do` / `then`: до 4 действий по порядку. `if`: `{"connection": "wired" | "bluetooth" | "2.4g"}` или
  `{"system": "windows" | "mac" | "ios" | "android"}`, тогда `then` при совпадении и `else` иначе. Пустой `else` оставляет
  заводское поведение.
- Действия: `USB`, `2.4G`, `BT1`..`BT3`, `WIN`, `MAC`, `IOS`, `ANDROID`, `FN+<клавиша>` (то же, что заводская комбинация),
  или код вида `"0xDB"`.
- Не больше одного действия подключения на список, и оно должно быть последним. Сборка не примет файл, нарушающий правила.

## Сборка и проверка

```
python firmware\source\build_firmware.py --stock stock_image.bin --macros my_macros.json --out patched_image.bin --patch-out my_macros.patch.json
python firmware\apply_patch.py путь\к\AULA_F108_Pro_Firmware.exe --patch my_macros.patch.json
cd dev
python fn_macros_test.py stock_image.bin patched_image.bin ..\firmware\macros\my_macros.json
```

Тест в эмуляторе нажимает триггер на пропатченном образе и настоящие FN-комбинации действий на заводском, через заводскую
обработку клавиш, и сравнивает состояние клавиатуры. Радио и USB в эмуляторе нет, поэтому результат стоит проверить и на клавиатуре.
