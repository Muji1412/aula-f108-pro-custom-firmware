# Кастомная прошивка AULA F108 Pro, поддержка OpenRGB и меню подсветки на экране

Неофициальный проект. Не связан с AULA и Sonix и не одобрен ими. "AULA" - товарный знак своего владельца.
English version: [README.md](README.md)

Проект патчит прошивку клавиатуры AULA F108 Pro (микроконтроллер Sonix SN32F290, экран 240x135, колёсико) и добавляет для неё
контроллер OpenRGB.

## Что получаешь

- Уровень заряда на зоне подсветки над стрелками: градиент от красного к зелёному, мигает при заряде ниже 20 процентов.
- Две новые страницы меню на экране (листаются колёсиком):
  - SIDE LIGHT: эффект, цвет, скорость и яркость двух боковых полос (четыре кружка на одном экране).
  - ARROWS: режим (заряд, заводской, один цвет, дыхание, радуга, выкл), цвет, скорость, яркость зоны над стрелками.
- В режиме громкости (переключается FN) нажатие на колёсико теперь Play/Pause (раньше Mute).
- Прямое управление всеми светодиодами (клавиши, зона над стрелками, боковые полосы) с компьютера по кабелю и через донгл 2.4G.
  Цвета хранятся только в оперативной памяти, во флеш ничего не пишется, ресурс не тратится.
- Контроллер OpenRGB для этого режима (кабель и 2.4G).
- Необязательные FN-макросы: одна FN-комбинация выполняет список заводских действий (подключение, системный режим, подсветка),
  при желании в зависимости от текущего подключения или режима. Готовый вариант: FN+W переключает кабель + Windows / 2.4G + Mac.
  Подробно: [docs_ru/09-fn-macros.md](docs_ru/09-fn-macros.md).

Всё остальное работает как раньше: заводские эффекты, FN-комбинации, часы, GIF, программа-драйвер.

## Что нужно

- AULA F108 Pro (USB 0C45:800A по кабелю, донгл 05AC:024F). Другие модели не поддерживаются.
- Официальный `AULA_F108_Pro_Firmware.exe` от производителя, именно той версии, под которую сделан патч. Патчер сам проверяет
  версию и другую не примет. Контрольные суммы лежат в `firmware/patch_data.json`.
- Windows для прошивки (официальная утилита работает только там). Часть про OpenRGB можно собрать и под другие системы.
- Python 3.8 или новее для патчера и скриптов.

## Быстрый старт

1. Скачай официальный `AULA_F108_Pro_Firmware.exe` с сайта производителя.
2. Выполни `python firmware/apply_patch.py путь\к\AULA_F108_Pro_Firmware.exe`. Рядом появится `AULA_F108_Pro_Firmware_CUSTOM.exe`.
3. Подключи клавиатуру USB-кабелем, запусти новый exe, нажми Start, дождись "Update successfully".
4. Меню: [docs_ru/02-menu.md](docs_ru/02-menu.md).
5. OpenRGB: [docs_ru/03-openrgb.md](docs_ru/03-openrgb.md).

Подробно про прошивку: [docs_ru/01-flashing.md](docs_ru/01-flashing.md). Как это делалось и что найдено: [docs_ru/08-research-log.md](docs_ru/08-research-log.md). Если что-то пошло не так: [docs_ru/05-recovery.md](docs_ru/05-recovery.md).

## Что внутри

| Путь | Что это |
|---|---|
| `firmware/apply_patch.py`, `firmware/patch_data.json` | Патчер. Содержит только байты проекта, чужого кода нет. |
| `firmware/source/` | Исходники патча на C и ассемблере и скрипт сборки (для разработчиков). |
| `firmware/macros/` | Примеры FN-макросов и готовые файлы патча для `apply_patch.py --patch`. |
| `openrgb/` | Исходники контроллера OpenRGB (GPL-2.0-or-later, как и сам OpenRGB) и скрипты установки. |
| `tools/` | Python-утилиты: прямой RGB по кабелю и донглу, маленькая студия RGB, чтение заряда. |
| `dev/` | Эмулятор прошивки (Unicorn) и скрипты для проверки до прошивки. |
| `docs/`, `docs_ru/` | Документация на английском и русском. |

Официальной прошивки, утилиты, драйвера и картинок в репозитории нет и добавлять их нельзя.

## Риски

Прошивка клавиатуры всегда связана с риском. Автор прошил несколько сборок на одном экземпляре без проблем, но проверить другие
экземпляры не может. Используй кабель, не выдёргивай его во время прошивки, прочитай [docs_ru/05-recovery.md](docs_ru/05-recovery.md)
заранее. Можно потерять гарантию. Всё предоставляется как есть, без каких-либо гарантий, ты используешь это на свой страх и риск.
